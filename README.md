## Play in your browser

**[bradmartin333.github.io/BoopQuest/Web](https://bradmartin333.github.io/BoopQuest/Web/)**

The web version runs the original Arduino sketch on an emulated 16x2 LCD, three buttons and a piezo buzzer, all in plain JavaScript.

| Button | Keyboard |
| --- | --- |
| Left | `A` or `←` |
| Select | `S`, `↓`, `Space` or `Enter` |
| Right | `D` or `→` |

On the Toy Organ, hold buttons together to play chords, and hold all three to exit. On a phone, use multiple fingers.

To run it locally, serve the `Web` folder over HTTP.
